# Growth Audit status icons

The two PNG files are source icons obtained from
[Noun Project](https://thenounproject.com/). CSS uses their alpha channels as
optically sized masks so ShowUp can apply theme-safe status colours. The Empty
state is a native CSS dot and does not use an external asset.

- `status-flat.png`: [“Minus” by ARIPATUT DASUKI](https://thenounproject.com/icon/minus-8363736/).
- `status-up.png`: [“Trend” by Travis Avery](https://thenounproject.com/icon/trend-2344331/).

The source artwork is bundled at 512×512 and displayed with per-icon mask sizes
that compensate for the different transparent padding in each source file.
Creator attribution also appears in Growth Audit’s information control.
